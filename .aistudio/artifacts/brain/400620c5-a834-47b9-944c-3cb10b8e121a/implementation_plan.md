# План редизайна главного экрана приложения (`src/Home.jsx`)

Мы продолжаем модернизацию мини-приложения строго в соответствии с правилом: **один файл за раз, сохраняя 100% существующих интеграций и связок**.

---

## 1. Архитектурный обзор и статус приложения
- **Работоспособность**: Сборка (`vite build`) и линтинг проходят чисто без ошибок.
- **Интеграции**:
  - `ServiceBooking.jsx`: переведен на новый эргономичный мобильный интерфейс без упоминаний 1С для клиентов, с поисковым Bottom Sheet марок и сохранением всех запросов к 1С и Bitrix24.
  - `Home.jsx`: связывает авторизацию Telegram WebApp, баланс бонусов (`communication/contact/bonus`), автомобили гаража (`api/profile/cars`), счетчики витрины и заявки на Trade-in.

---

## 2. Цель редизайна `src/Home.jsx`
Превратить главный экран в премиальный мобильный дашборд автодилера для Telegram WebApp:
- **Крупные удобные тач-зоны (touch targets)**: кнопки высотой от 50px, крупные шрифты, контрастные заголовки.
- **Виджет активного автомобиля из Гаража**: если у клиента подгружена машина, выводить карточку с быстрым переходом в запись на сервис в один клик. Если машины нет — красивый блок «Добавить авто».
- **Интерактивный блок бонусов**: крупный визуальный баланс баллов с кнопкой перехода в профиль/бонусную карту.
- **Быстрые действия (Quick Actions)**: сетка ключевых сценариев («Запись на сервис», «Каталог новых», «Авто с пробегом», «Оценка Trade-in», «Акции») с яркими иконками и понятными статусами.
- **Сохранение всех API и функций**:
  - `BASE_URL` запросы (бонусы, гараж, счетчики).
  - Модальное окно экспресс-оценки Trade-in с отправкой формы.
  - Навигация React Router (`/service`, `/showcase`, `/profile`, `/tires`, `/offers`).
  - Telegram/Max SDK (`platform.getUser()`, `platform.getId()`).
